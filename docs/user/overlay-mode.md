# Overlay mode

Overlay mode is a small window that floats over your other apps and lists the
threads you have not looked at yet: an agent finished, failed, asked a
question, or needs an approval. It is part of the desktop app and is on by
default.

The overlay hides while T3 Code has focus, because the sidebar already shows
the same things. When nothing needs you it shrinks to a small bar that says how
many agents are still working. Drag the overlay anywhere; it remembers its
place.

A thread counts as seen when it is open in a focused T3 Code window. Opening a
thread drops it from the overlay even if the agent still waits on you; the
sidebar keeps showing it until you answer. Hover a row and press **×** to hide
that thread from the overlay without opening it. It stays unread in the
sidebar, and comes back to the overlay when the agent does something new.
**Bring back hidden threads** in the overlay menu restores them all.

The overlay's menu (**⋯**) hides it for an hour, until tomorrow morning, or
until you turn it back on. Turn it off or on in **Settings → General →
Overlay mode**. Turn off **Overlay pill when nothing needs you** to keep the
overlay off screen until a thread needs you.

## Step away mode

Step away mode shows the same list at a size you can read from across the
room, and keeps the display awake while it shows. Turn it on from the coffee
cup button in the thread header or from the overlay menu. It stays on screen
even while T3 Code has focus, and it ignores an overlay hide. Press **I'm
back** on the overlay or the coffee cup button again to leave it. Step away
mode does not survive a restart.
