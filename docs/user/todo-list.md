# To-do list

## Keep your next steps in order

The **to-do list** holds what you plan to do next, in the order you plan to do it. Open it with
the checklist icon in the top-right corner, or from the command palette.

The list belongs to the server, not to the thread you opened it from. Every thread shows the same
list, and so does every device connected to that server: the desktop app, a browser and the phone
all read and write the same items.

## Working with the list

- Type in the box at the bottom and press Enter to add an item.
- Drag an item by its handle to move it. The order is the priority, so the next thing goes on top.
- Click an item's text to rewrite it. Enter stores the change, Escape drops it.
- Press the tick to mark an item done. It moves to a **Done** section at the bottom.
- Press the arrow on a done item to put it back, or **Clear done** to remove them all.
- Press the cross to delete an item outright.

Every change is stored as you make it. There is no save button.

## The list and the daily summary

The server records when you add an item and when you tick it off. The **daily summary** reads the
items you ticked off on the day it reports, so work you tracked only on the list still reaches
your standup.

**Clear done** hides the items from the panel. The server keeps them for a month so a day you
already tidied up can still be summarised.

## What the list is not

The list is yours to write. T3 Code never adds an item to it, and an agent cannot read it or
change it.
